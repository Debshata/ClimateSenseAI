## Stage chronology

1. Smoke tests (2 epochs) of GRU and MAF-Net to verify the pipeline (excluded from results).
2. Initial runs with default hyper-parameters (`experiments/multimodal`).
3. Optuna tuning (`experiments/tuning`, `optuna.db`). The tuning processes were restarted once to cap PyTorch CPU threads (CPU contention); trials in flight at that moment are recorded as INTERRUPTED. Because the TPE sampler is seeded, the restarted worker re-proposed some earlier configurations; these duplicates were served from the run cache and count toward the trial budget. MAF-Net used two parallel workers (sampler seeds 42 and 43) on one shared study, capped by `MaxTrialsCallback`.
4. Multi-seed retraining of the selected configurations (`experiments/final`).
5. Ablations, horizons, look-back, spatial hold-out.
6. Single held-out test evaluation (`scripts/evaluate_models.py`).
